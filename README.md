# Stellar Odyssey

A cinematic Three.js universe with a procedural galaxy, a fully animated planetary system, nebulae, accretion disks, interactive focus targets, a guided tour, and Kepler-based orbital motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Explore

- Drag to orbit, right-drag to pan, and scroll or pinch to traverse.
- Click any named star, planet, black hole, comet, or nebula landmark to focus and inspect it.
- Use the left navigation to jump between scales.
- Use the lower-left chronometry panel to pause or change simulation speed.
- Select `PERTURB LAB` to kick the small Newtonian particle system.
- Press `1`, `2`, `3`, or `4` for landmark jumps and `Space` to pause.

Implementation and design decisions are documented in `docs/ARCHITECTURE.md`.
